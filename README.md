# Hasaki – Cân task B2 Bảo trì

Công cụ điều phối task bước **B2. Tiếp nhận và xử lý yêu cầu** (Workflow 398) cho đội bảo trì Điện / Điện Lạnh / IT Helpdesk.

- **Bảng task**: cân tải theo Zone, đổi người thực hiện từng task hoặc hàng loạt.
- **Điều phối ngày mai**: kéo thả task vào từng nhân viên theo ca làm.
- **Báo cáo ngày**: đã làm / còn treo / ngày mai, kèm ca làm, sao chép gửi Zalo, tải CSV.

Mở trang, dán token Bearer của Work (wshr) rồi bấm **Tải dữ liệu mới nhất**. Token chỉ lưu trên trình duyệt của người dùng (nếu tick "Ghi nhớ"), không nằm trong repo.
